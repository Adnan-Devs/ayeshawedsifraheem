# Ayesha weds Ifraheem 💍

Animated wedding invitation (Punjab, Pakistan): name + invitation-code lock, envelope opening, scratch-to-reveal date, countdown, event cards and a dhol beat.

**Edit details:** open `index.html` and change the `CONFIG` block near the bottom (guest list, code, dates, venues, families).
**Own dhol music:** upload an audio file (e.g. `dhol.mp3`) here and set `music: "dhol.mp3"` in `CONFIG`.
